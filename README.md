# IDEAL Eyewear

An interactive 3D eyewear concept designed and developed as a front-end portfolio project.

## Live Demo

https://mas-dragon.github.io/Glasses-site/#/

## Overview

IDEAL is a fictional premium eyewear brand created to demonstrate interactive product presentation, responsive design, animation and 3D web development.

## Technologies

- React
- React Router
- Three.js
- React Three Fiber
- Drei
- Framer Motion
- CSS
- Context API

## Features

- Interactive 3D eyewear model
- Scroll-driven animation
- Responsive desktop and mobile experience
- Product collection and details
- Lens comparison interaction
- Shopping-cart interface
- Demo checkout flow

## Role

UI/UX Design and Front-end Development

## Disclaimer

This is a fictional portfolio concept. Products, prices, reviews and checkout functionality are for demonstration only.
